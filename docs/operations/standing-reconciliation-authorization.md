  client communication, Slack publication, push, merge or deployment is granted
  by this authorization.
- Keep private source text, caches and immutable receipts private. Send only
  evidence necessary for the work reconciliation, not unrelated private data.

standing permission to push, merge or deploy, and a local clone's origin must
not be mistaken for the authoritative GitHub remote.
